# BONA BONA SCHOOL

## 公開先

- トップページ: https://korugi-school.jp/
- 限定公開動画ページ: https://korugi-school.jp/premium/
- 個別相談フォーム: https://korugi-school.jp/consultation/

## 変更時に守ること

- 正式表記は「BONA BONA SCHOOL」で統一する。
- トップページは公式LINEへの登録を目的とするため、個別相談フォームへの導線には変更しない。
- 個別相談の導線は限定公開動画ページから `/consultation/` へつなぐ。
- 個別相談フォームの送信先は、指定スプレッドシートに接続したGoogleフォームを使用する。
- 指定した2つのメールアドレスへの通知は、Google側の権限ブロックにより未設定。
