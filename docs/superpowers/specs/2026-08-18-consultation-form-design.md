# BONA BONA SCHOOL 個別相談フォーム設計

## 目的

限定公開のスクール説明動画を見た方が、公式LINEを経由せず、サイト上から個別相談を申し込めるようにする。

## 対象範囲

- トップページは公式LINEへの登録を目的とするため変更しない。
- 限定公開動画ページ内の個別相談ボタンを、新しい申し込みフォームへの導線に変更する。
- 限定公開動画ページ内の申し込み手順を、フォーム利用に合わせて変更する。
- BONA BONA SCHOOLの既存デザインに合わせた個別相談フォームページを新設する。
- フォーム送信内容をGoogleフォーム経由で、指定のGoogleスプレッドシートへ保存する。
- 指定した2つのメールアドレスへの通知は、Google側の権限ブロックが解消した後に別途設定する。

## ページ構成

### 限定公開動画ページ

- メインボタンの表示を「個別相談を申し込む」に変更する。
- 画面下部の固定ボタンも同じ表示と遷移先に統一する。
- LINEのトーク画面に関する説明と代替リンクは削除する。
- 「お申し込みの流れ」を、フォーム入力から折り返し連絡までの内容に変更する。

### 個別相談フォームページ

- URLは `/consultation/` とする。
- 見出しは「個別相談お申し込み」とする。
- フォーム上部に、入力内容を確認後に連絡する旨を記載する。
- BONA BONA SCHOOLの既存の色、文字、余白、ボタン表現を引き継ぐ。
- スマートフォンとパソコンの両方で入力しやすい配置にする。

## 入力項目

以下をすべて必須項目とする。

1. 氏名
2. メールアドレス
3. 電話番号
4. 都道府県
5. お悩み
6. LINE名

都道府県は選択式、お悩みは複数行入力、その他は1行入力とする。

## 送信時の動作

1. 未入力項目、メールアドレス、電話番号の入力形式を画面上で確認する。
2. 入力に問題がなければ送信ボタンを一時的に無効にし、二重送信を防止する。
3. 公開済みのGoogleフォームへ、6項目を対応する設問IDで送信する。
4. Googleフォームと連携した指定スプレッドシートに、受付日時と6項目を1行で保存する。
5. 送信先は非表示iframeとし、サイトから画面遷移せずに受け付ける。
6. 受付後は「お申し込みを受け付けました。内容を確認後、ご連絡します」と表示する。

## Googleスプレッドシート

- ユーザー指定の共有スプレッドシートを使用する。
- Googleフォームを同スプレッドシートから作成し、回答シートへ自動保存する。
- 列は「受付日時、氏名、メールアドレス、電話番号、都道府県、お悩み、LINE名」の順とする。
- サイト側には公開Googleフォームの送信先と設問IDのみを設定し、個人情報や秘密の値は埋め込まない。

## 通知メール（保留）

- Apps Scriptのスプレッドシート権限・メール送信権限は、連携スクリプトと単独スクリプトの両方でGoogleにブロックされた。
- Googleフォーム標準の回答通知はフォーム所有者宛てに限られ、`bonabonabeauty@outlook.jp` と `shiokaka@gmail.com` の2宛先を任意指定できない。
- 個人情報を第三者サービスへ渡す構成には切り替えず、メール通知はGoogle側の権限を利用できるアカウントで別途設定する。

## 確認項目

- 必須項目の未入力時に送信されないこと。
- メールアドレスと電話番号の形式違いが案内されること。
- 正常送信時にスプレッドシートへ1行追加されること。
- Googleフォームの6項目とスプレッドシートの列が正しく対応すること。
- 二重送信が起きないこと。
- 送信失敗時に入力内容が消えないこと。
- スマートフォンで各項目と送信ボタンが操作しやすいこと。
- トップページの公式LINE導線が変更されていないこと。

## 公開手順

1. 現在のファイルを日付付きでバックアップする。
2. フォームページと動画ページの変更をローカルで確認する。
3. GoogleフォームからGoogleスプレッドシートへの保存を試験する。
4. 片岡さんに画面と動作を確認してもらう。
5. 公開承認後にGitHubへ反映する。
6. 公開URLで最終確認する。

メール通知はサイト公開とは分けて設定し、完了後に指定した2つの宛先への到達を確認する。
